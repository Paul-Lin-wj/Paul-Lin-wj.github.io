# paul-lin-wj.github.io

Personal site — 林晖洋 / Huiyang Lin.

Built with [Astro](https://astro.build). Content lives in `src/data/site.ts`
(both languages in one place); pages are thin wrappers around the components in
`src/components/`. Design tokens are at the top of `src/styles/global.css`.

```bash
npm install
npm run dev      # local preview at localhost:4321
npm run build    # static output to dist/
```

Pushing to `main` deploys via GitHub Actions.
